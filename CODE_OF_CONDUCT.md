# Code of Conduct

## Our standard

Participants should make the project a respectful, harassment-free place for technical
collaboration. Be specific, evidence-backed, and considerate. Disagreement about design
is welcome; personal attacks, harassment, discriminatory conduct, and disclosure of
private information are not.

## Scope

This standard applies in project repositories, issue trackers, review threads, release
discussions, and other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately to the project maintainer through the contact channel
listed in the repository profile. Security vulnerabilities belong in GitHub private
security reporting. Reports will be reviewed fairly and confidentially where possible.

Project maintainers may edit or remove contributions that violate this standard and
may temporarily or permanently restrict participation when needed to protect the
community.

## Attribution
