# Roadmap

This roadmap records demand-driven possibilities, not delivery commitments.

## Stable in Beta 4

- Deterministic task-specific eligibility and rank-preserving fallback.
- Explicit provider trust and exact evidence/resource binding.
- Typed uncertainty and content-addressed DecisionReceipts.
- Python, JSON/stdin, and loopback HTTP integration surfaces.

## Experimental

- Generalized provider and evaluator SPIs.
- MCP fact collection and A2A, OpenAPI, Skill, and Neuronto parsing boundaries.
- Publisher identity, access, dependency, deployment, lifecycle, quota, observed-fitness,
  and federation requirement packs.

Experimental means qualified against local fixtures, not official upstream adoption.

## Research and demand-driven follow-up

- Track ARD and hf-discover wire changes through pinned fixtures.
- Improve provider ergonomics only from independent integration feedback.
- Add integrations only when a current upstream or user need is reproduced.
- Consider live evaluation hosting only after the static Explorer demonstrates need and a
  separate security review is complete.

## Explicitly out of scope

- A universal trust score.
- Replacing relevance ranking.
- Automatic resource invocation or remediation.
- Building or operating a registry.
- Adding ecosystem integrations without a reproduced technical seam.
