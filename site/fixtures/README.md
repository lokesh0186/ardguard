# Decision Explorer fixture provenance

These twelve public fixtures are generated by ARDGuard's real Python decision engine.
The browser only renders the resulting input and DecisionReceipt data; it does not
reimplement eligibility or fallback semantics.

Regenerate from the repository at the Beta 4 source commit:

```bash
python -m pip install ardguard==0.1.0b4
python scripts/generate_site_fixtures.py
python scripts/generate_site_fixtures.py --check
```

`hashes.sha256` records the SHA-256 digest of every scenario fixture. Each fixture also
records `engine.package_version`, the scenario input, decision, receipt, and presentation
data used by the Explorer.
