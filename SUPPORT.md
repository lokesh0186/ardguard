# Support

The latest published `0.1.x` prerelease is supported within
[`docs/SUPPORTED_SCOPE.md`](docs/SUPPORTED_SCOPE.md). Compatibility is exact and
versioned; untested future ARD or hf-discover shapes are not silently accepted.

Open a public bug for a minimal non-sensitive reproduction. Use GitHub private security
reporting for a possible fail-open decision, subject-binding error, authority-policy
bypass, path escape, or sensitive evidence.

Include:

- ARDGuard version and install source;
- Python and operating-system versions;
- adapter or provider identity and version;
- the smallest sanitized task, policy, candidates, and observations;
- actual and expected decision;
- whether retry changes the result.

Do not post credentials, private resource catalogs, verifier trust material, or
third-party data without permission.
